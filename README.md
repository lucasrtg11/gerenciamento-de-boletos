# 💰 Sistema de Cobrança de Boletos

Sistema completo para gestão de cobranças, desenvolvido para automatizar controle financeiro e reduzir erros manuais.

---

## 🚀 Funcionalidades

- ✔ Cadastro de boletos
- ✔ Edição de boletos
- ✔ Atualização de status (ABERTO, PAGO, CANCELADO)
- ✔ Reabertura de boletos
- ✔ Controle de vencimentos
- ✔ Identificação de boletos atrasados
- ✔ Interface moderna e responsiva

---

## 🛠️ Tecnologias

- Next.js
- React
- Prisma ORM
- PostgreSQL
- TailwindCSS
